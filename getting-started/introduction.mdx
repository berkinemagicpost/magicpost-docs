## What MagicPost?

MagicPost is a self-hosted web application for planning, scheduling and publishing social media posts. You install it on your own server and register an app with each social network once. Your users then connect their accounts as channels and publish to all of them from one place.

It is built on Laravel 12 and Livewire. It needs PHP 8.3 or newer, a MySQL database and one cron job, and it is designed to run on ordinary shared hosting that only offers cron.

## Supported networks

Users can publish to X (Twitter), LinkedIn, Facebook Pages, Instagram, TikTok, YouTube, Pinterest, Threads, WhatsApp and Telegram. Each network needs its own developer app, gateway or bot, which you set up once under Admin → Publishing → Platforms. See [Publishing channels](/channels/overview) for how credentials and connections work.

## How publishing works

<Steps>
  <Step title="The admin registers the network apps">
    Each network is switched on under Admin → Publishing → Platforms once its credentials are saved and **Available to users** is ticked.
  </Step>
  <Step title="Users connect channels">
    From **Channels**, a user authorises MagicPost on the network and returns to the site. Every connected account, page or group is a channel.
  </Step>
  <Step title="Users compose posts">
    In the **Composer** a post is written once, adjusted per channel, and sent now, at a chosen time, to the next free queue slot, or on a repeat.
  </Step>
  <Step title="The scheduler sends them">
    Your cron job runs the Laravel scheduler every minute. It picks up posts that are due, queues them and sends each one to its channels. A post can succeed on some channels and fail on others.
  </Step>
</Steps>

<Note>
SaaS Business is optional. While it is switched off, no plan limits apply and every feature is available to every account. Turning it on makes plans and the free tier decide what each account can do.
</Note>
