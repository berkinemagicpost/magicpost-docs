The admin panel is the part of MagicPost that only accounts in the **Admin** group can open. Every admin screen lives under `APP_URL/app/admin/`, and the first one you land on is the [Admin dashboard](/admin/dashboard).

Admin accounts see one sidebar with two menus. The personal menu at the top (Home, Notifications, Publishing, Library, Workspace, Help) is the same product your customers use, so you can publish with your own account. The admin items follow below it.

<Note>
  Items under **Finance**, **Affiliates** and the **Plans** group of the personal menu only appear after SaaS Business is switched on. See [SaaS overview](/saas/overview).
</Note>

The **Backend Settings** and **Frontend Settings** entries are collapsed groups. Click the group name to open it.

## Where to find a setting

| You want to | Go to |
|---|---|
| Let customers connect X, LinkedIn, Facebook and the other networks | Publishing, **Platforms** |
| Make sure scheduled posts leave on time | Publishing, **Settings** (System health and Sending) |
| Add an OpenAI, Gemini, Anthropic or xAI key for captions | Publishing, **Writing Models** |
| Add keys for AI pictures and video | Publishing, **Media Models** |
| Give new sign-ups starting credits | **General Settings**, Default Registration Credits |
| Change the site name, site URL or time zone | Backend Settings, **Global Settings** |
| Close registration or require email verification | Backend Settings, **Registration Settings** |
| Add Google, Facebook, X or LinkedIn sign-in | Backend Settings, **Auth Settings** |
| Send real emails | Backend Settings, **SMTP Settings** |
| Replace the logo or favicon | Frontend Settings, **Logos** |
| Edit the Privacy Policy and Terms of Service | Frontend Settings, **Pages** |

<Note>
  A System Status page exists at `APP_URL/app/admin/status`, but it is not in the sidebar and it does not report server health. Use the checks described in [System status](/admin/system-status).
</Note>
