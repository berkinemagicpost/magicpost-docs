Plugins are optional add-ons from the MagicPost marketplace. An administrator installs them from the admin panel with one click, and each plugin adds its own settings or features to the app. Instructions for individual plugins are kept in this section, one page per plugin.

<Note>
This page covers what every plugin has in common. The catalogue itself, with its badges, buttons and license-key options, is described in [Plugins and themes](/admin/plugins-and-themes).
</Note>

## Before you install

- Your license must be active. The plugin catalogue is loaded from the marketplace with your license, so an inactive license gives an empty list. See [License activation](/license/activation).
- Your server must be able to reach the internet to download the plugin.
- Your MagicPost version must meet the plugin's minimum. If it does not, the button on the plugin page reads **Requires app version** and stays disabled until you update. See [Update instructions](/updates/update-instructions).

## Install a plugin

<Steps>
  <Step title="Open the catalogue">
    In the admin sidebar, open **Platform**, then **Plugins**. Use **Search your plugins...** or the **All**, **Installed**, **Paid** and **Free** tabs to find it.
  </Step>
  <Step title="Get access">
    A free plugin installs straight away. For a paid plugin, click **Buy Now** and pay on the payment screen, or enter a license key you already own. Holders of an Extended License can install plugins marked **Free for Extended** without paying. See [Extended license](/license/extended-license).
  </Step>
  <Step title="Install">
    Click **Install** on the card, or **Install Plugin** on the plugin page. MagicPost downloads the files, unpacks them and activates the plugin, usually within seconds.
  </Step>
  <Step title="Set it up">
    Open the plugin's page in this section and follow its setup steps.
  </Step>
</Steps>

## Update a plugin

A card with the **Update Available** badge has a newer version in the marketplace. Click **Update** on the card to install it.

## Uninstall a plugin

Click the trash icon on the plugin's card, or **Uninstall** on its page, and confirm. MagicPost removes every file the plugin added and disables it.

<Warning>
Uninstalling a plugin removes the features it added. If it was unlocked with a license key, you need to enter the key again before you can install the plugin again.
</Warning>

## Where plugin settings appear

Each plugin decides where its settings live. The SaaS plugin, for example, adds a **SaaS Business** card under **General Settings**, **Plugins**. See [General settings](/admin/general-settings) and the [SaaS overview](/saas/overview).
