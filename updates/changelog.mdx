<Update label="Version 1.0" description="Initial release">

  ### Publishing

  - Publish to X (Twitter), LinkedIn, Facebook Pages, Instagram, TikTok, YouTube, Pinterest, Threads, WhatsApp and Telegram. An admin registers each network under **Publishing → Platforms**, and users connect their accounts from **Channels**.
  - A **Composer** with a shared caption, an own caption and options per channel, a first comment, a link, labels, a live preview per channel, rule checks before a post goes out, and drafts that save automatically.
  - Scheduling at a time, into the next free slot of a posting **Queue**, or on a repeat. Evergreen posts, a **Calendar** and a **Posts** list with statuses.
  - Retries, a waiting limit for channels that are paused or need reconnecting, and recovery of sends that stalled.
  - An **Approvals** workflow and **Teams** with the roles owner, member and approver.
  - **Feeds** that turn new RSS articles into posts, and CSV import and export of posts.
  - **Analytics** for channels and posts, collected hourly from the networks.
  - In-app **Notifications** for publishing events.

  ### Media and AI

  - A media library with chunked uploads, folders, alt text, per-channel crops and an optional watermark applied to images as they go out.
  - **Write with AI** for captions, saved **Captions**, and **Brand voices**.
  - Image and video studio for AI-generated media, with credits charged per run.
  - Writing and media models are managed by the admin under **Publishing → Writing Models** and **Media Models**.

  ### Developer features

  - A REST API under `/api/v1` with read and write tokens.
  - User webhooks for post events.

  ### Admin panel

  - Dashboard, user management with activity monitoring, and support tickets.
  - **Publishing → Settings** with a **System health** check, the queue mode, retry and upload limits.
  - General, Global, Auth, Registration, SMTP and GDPR settings, frontend settings, a blog manager, the Language Manager, plugins and themes.
  - System notifications for announcements.

  ### SaaS and billing

  - Optional SaaS Business: pricing plans, a free tier, credits, orders, subscriptions, invoices and finance settings.
  - Payment gateways, a wallet and bank transfer.
  - A referral program with accounts, earnings and payouts.

  ### Installation and licensing

  - A web installer that checks requirements, saves the database connection, builds the tables and activates the license.
  - License activation and deactivation from the admin panel, and one-click updates from **Platform → Update**.

</Update>
